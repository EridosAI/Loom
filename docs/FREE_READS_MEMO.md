# FREE-READS MEMO — the pre-SCATTER reads (recipes pre-named, committed before any read runs)

**Status: OPERATING MEMO (2026-07-12, after the EXP17 CLOSE at `af9d91c`; canon §10.27; navigation =
`PATHWAY_FORWARD.md` Step 3). This memo is committed BEFORE any of these reads executes.** It exists
so the recipes are on the record first and cannot be back-fitted to a desired answer.

Four read-only diagnostics precede the SCATTER-DWELL prereg (the bracketing arm, `MECHANISM_MAP_v1_2_RECONCILED.md`
§3). They are named here with recipe, ordering, and **pre-named consequence** so each is a bet placed
in advance, not a result narrated after the fact.

## Standing rules for all four reads

- **Read-only.** No checkpoint, record, or committed artifact is modified. These read; they do not write
  to canon. Each produces its own untracked result artifact + a one-line finding.
- **Report-don't-patch.** A read that surfaces a defect (in a committed record, a recipe, or a prior
  claim) is *reported*, never silently corrected. Committed artifacts stay untouched.
- **Results route to the design seat BEFORE any design consumes them.** No read's output may enter a
  prereg, a selection statistic, an attribution, or a canon line until the seat has seen it and ratified
  what it means. A free read informs the next design step; it does not *become* one on its own.
- **Pre-named consequences bind.** The consequence written beside each read below is the ruling that
  fires if the read lands that way — chosen now, before the number exists, per the manufacturing fence.
- **Ordering:** (i) render-gain runs FIRST — it gates SCATTER's F5 selection statistics and it
  qualifies the close's "as tested." The other three are independent and may run in any order.

## (i) Render-gain audit — RUNS FIRST; gates SCATTER's F5; qualifies the close's "as tested"

**Recipe (`MECHANISM_MAP_v1_2_RECONCILED.md` §4, verbatim):** per-dwell **mean render-step / pose-step
ratio along the realized L1 (orbit) trajectory** vs **the same ratio over random pose pairs**.
Fabric-only, deterministic, computable from the frozen L1 fabric + the committed renderer at any time —
no EXP17 amendment needed (the audit was designed with retroactive reach). Retroactive on L1; a
standing pre-flight read for every ladder arm thereafter.

**Why it is load-bearing now:** the kinematic floors live in pose space; the learner lives in render
space. If pose-axis appearance gains are anisotropic, a random orbit plane can be kinematically
compliant yet *perceptually weak* — in which case the orbit's transient-only result is partly
perceptual.

**Pre-named consequences:**
- **Severe anisotropy on L1's audit →** a **ratification-class gain floor** is added to SCATTER's ball
  sampling (its F5 selection statistics gain a render-gain floor; RED_TEAM **F5** is filled with this
  floor in place, not without it). Ratification-class = routes to Jason, not folded silently.
- **Either way →** the audit **qualifies §10.27's "did NOT convert as tested"**: a weak-render finding
  scopes "as tested" to the perceptual regime the L1 planes actually delivered.
