# Frozen passive analysis conventions

NON-CANONICAL RESURRECTION SANDBOX. No simulation, state advancement, RNG draw, alternate trajectory or canonical modification. This is observer analysis, not a pass/fail rubric. The previous curve package and original evidence remain unchanged.

## Functional timing

Each recorded wave contains new outgoing regulator controls but a motor diagnostic from the last native operation, which consumed the previous controls. Match the latter against the preceding stored wave (birth output for the first wave). Verify both current and attenuation identity. Omissions hold that operation's M1, direct feedback, previous tendency, exploration and need fixed. Compute only the algebraic change at its receiver, using its actual stored elapsed interval. No updated state is constructed or carried onward.

For current-only omissions: Δu = (1−attenuation) α [tanh(z)−tanh(z−Δcurrent)], α=1−exp(−dt/tau_motor). A second result removes the bank's learned contribution from both current and attenuation. This is the immediate effect at ONE stored operation. It is not the accumulated learned effect over a counterfactual motor history. Ratios to M1 input use trailing 60-second RMS numerator/denominator, not a mean of unstable instantaneous ratios. Also report same-receiver M1 omission as a scale comparator. Bank norms used in coupling ratios are the preceding bank state which produced those controls. H/q/use remain measured completed-wave values.

## Physical events and opportunities

Use all native endpoints and exact event ledgers. Geometry is observer-only. Source surface gap = centre distance minus body/source radii. Rectangle and wall gaps include finite body radius. Hazard identity is used for opportunity/outcome accounting only, never a context feature.

An approach episode enters <=0.5 surface units, stays open until >1.0 units, and contains measured closing motion >0.01 units/s before contact (birth-near episodes are labelled separately). Sensitivity uses entry/exit 0.25/0.5 and 1.0/1.5. Contact episodes merge same-collider fragments only when gaps <=1 second and maximum intervening surface clearance <=0.25 units; source sensitivity uses gaps 0.2/1/5 and clearances 0.05/0.25/0.5. Collisions are positive instantaneous impact impulses, grouped within a 1-second same-collider episode; sustained constraint impulses are reported separately. Exact isolated impact closing speed is impulse/mass; multi-contact closing speed is unavailable. Sampled pre-event relative normal velocity is labelled a proxy, never exact impact speed.

Source neighborhood entry/exit is gap <=1 / >1.5 units. A true same-source return requires leaving >0.25 units after contact; neighborhood return requires leaving >1.5. Brush-like = <1 second actual contact. Productive = recorded transfer >0; no competence inference. Remaining near at 5/30 seconds is evaluated only when that follow-up exists. The final incomplete approach/repair interval is censored, not counted as a miss.

Rates divide by time, path, genuine approaches, or contact duration as appropriate. Body-capability strata use E <0.2 / 0.2–0.45 / >=0.45, I <0.9 / >=0.9; speed <0.03 / 0.03–0.08 / >=0.08. Report overlap and no-opportunity cells; do not extrapolate unmatched strata.

## Context matching, declared before looking at outcomes

Fixed two-second histories sampled at 0.1 seconds; candidate anchors at one-second spacing, no new sensory computation. Features: mean and endpoint of raw light[10], chemistry[4], proprioception[7]; mean/endpoint of actual paired command; actual E/I. Contact coordinates are excluded from the matching vector to avoid trivial identification of ongoing contact. Eligibility explicitly requires the preceding two seconds to be contact-free for hazard-anticipation matches. Post-impact sensory matching is separate. Global pose, collider/source ID, bearing, future clearance or outcome are NEVER distance features.

Each family is robustly normalized by within-life IQR with fixed 0.01 raw-coordinate floor and divided by sqrt(family width), then Euclidean RMS across families. This normalization is descriptive, uses observed states only and does not train a controller. Query collisions use the first genuine impact in each grouped collision bout, anchor 1 second before impact, with a contact-free preceding two-second history. Later candidates are >=60 seconds after query; matches must be >=10 seconds apart. Select nearest neighbors by sensory distance before reading outcomes. Report k=1,3,5 and distance caps 0.5,1,2; unmatched queries remain in denominator. Main cap=1, k=3. Follow-up is 10 seconds, only fully observed windows eligible. Physical hazard/source identity is determined separately at each anchor for outcome assessment, not matched between samples.

Productive-source queries use 1 second before the first transfer/contact bout, the same sensory distance and future 10-second horizon. Generic low-E, chemical-imbalance/rising-chemistry and post-impact samples use the same feature system for early/late action comparison. Matched pairs are serially dependent and outcome-conditioned queries are selected events: regression to the mean and non-equivalent geometry remain major confounds. No p-values, learned-avoidance proof or causal claims.

Main matched candidates also require |ΔE| <=0.10, |ΔI| <=0.05 and |Δspeed| <=0.03 units/s. They must have a complete 10-second outcome window. These calipers condition body capability without accessing future outcomes. The sensory distance is computed independently of these eligibility tests. Query/match identities, no-match cases, both distances and capabilities are retained. Physical opportunity overlap is reported after selection, not used to choose successful matches. An outcome-independent early-context sample (every 30 s through the first 600 s) is matched to later contexts as a bias comparison. Context-consistency/action changes use the selected samples, not an optimized prediction model.

## Longitudinal interpretation

Dashboard bands: 0–600, 600–1500, 1500–2500, 2500–3500, 3500–4500 s for the fixed seven complete lives. Other histories stay separate. Local functional slopes use Theil–Sen on five-second medians, in 300/600-second windows and the final 1000 seconds where available. Broad exploratory phase candidates minimize two-segment squared error on complete 60-second summaries with >=5 windows each side; all tested metrics are retained, with no significance threshold. Counterbalanced improvements and adverse sequences remain visible.

External support is not source energy or ordinary learning. Analyses flag distance to support and repeat natural-window comparisons outside 30-second margins (5/60 s sensitivity). Long duration itself and restored E still change capability and state visitation. Seven completed lives are a small administrative subset, not a large experimental sample.
