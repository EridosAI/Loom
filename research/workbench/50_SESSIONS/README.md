# Sessions and contributions

[Back to research map](../00_RESEARCH_MAP.md) · [Live status](../01_WORKSPACE_STATUS.md) · [Setup report](2026-09-20-setup-3ea17017/SETUP_REPORT.md)

Each session uses its own actual-date and unique-suffix directory. Start by reading [AGENTS.md](../AGENTS.md), the map, status and the exact sources for the assigned question. Read the pinned Current State first when consulting project history.

Jason assigns one current integration owner. The status entry records an assignment, not a technical lock. A later session must obtain or identify Jason's current assignment; an old owner entry does not grant authority indefinitely.

A concurrent contributor writes uniquely named proposal/review files in its own session directory, using the [session](../80_TEMPLATES/SESSION.md), [candidate](../80_TEMPLATES/CANDIDATE.md), [idea](../80_TEMPLATES/IDEA.md) or [review](../80_TEMPLATES/REVIEW.md) template. It does not edit the shared map, catalog, decision index or another contributor's files. Ordinary relative Markdown links are sufficient.

Before editing an existing authored note, read its complete current bytes and hash them. Immediately before replacement confirm the same hash. If it changed, preserve a proposed amendment in your session folder and ask the integration owner to reconcile it; do not overwrite, stash, reset or auto-merge. The integration owner can integrate navigation and accurately attributed status, but cannot make Jason's research decisions.

Use [intake instructions](../IMPORT_NEW_MATERIAL.txt) for a unique batch in INBOX and [contribution integration instructions](../INTEGRATE_CONTRIBUTION.txt) for a reviewable handoff. Existing source bytes remain untouched; revised complete candidates retain parents and differences. A parked branch needs a recorded reason and conditions for reconsideration; parked does not mean disproved.

Finish with a short durable record of actual reads (full or partial), changes, exact identities, open issues and validation. Assistant session notes are not verbatim chat exports. No plugin, database, scheduler or automatic project synchronization is required or configured.
