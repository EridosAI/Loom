# Founder Search v0.1 — design review package

Read `PLAIN_LANGUAGE_WALKTHROUGH.md` for the short explanation and `FOUNDER_SEARCH_v0_1_DESIGN.md` for the complete fourteen-part proposal.

`RESOURCE_CALCULATIONS.json` contains reused measurements and scalar projections. `SOURCE_INDEX.json` identifies exact references and their custody hashes. `references/` contains unchanged reference copies, including historical documents whose old permissions/status do not authorize any new work. `DELIVERY_VERIFICATION.json` records static checks; `PACKAGE_MANIFEST.json` binds the delivered files.

**Design only.** No simulation, world/prehistory evolution, P or controller execution, execution authority, code/configuration change, nursery build or Git write occurred. The package contains no launcher. Document hashes are custody checks, not authorization objects.

Jason selected 600 → 900 → 1,800 seconds as the design's total-age checkpoints. Population size, selection allocations and resource allowances remain proposals for review; the timing ruling grants no execution. Historical evidence, source files and workbench canon were preserved. The old sealed human B1 evaluator archive was not inspected.
