## Project instructions

This project contains the continuing Loom research program.

SOURCE HIERARCHY

1. Current committed canonical repository documents and verified artifacts
2. 00 - Loom Current State
3. Later session retrospectives
4. Earlier session retrospectives
5. Historical conversation material

Retrospectives are dated snapshots of what was believed, decided and pending
at the close of a session. They are not automatically current truth.

When using project history:

- Read 00 - Loom Current State first for orientation.
- Prefer later verified or committed material over earlier material.
- Do not silently reconcile contradictions.
- Separate:
  1. observed experimental evidence;
  2. decisions explicitly accepted by Jason;
  3. assistant proposals;
  4. unresolved interpretations.
- Do not convert a Claude suggestion into an accepted project decision.
- Preserve exact experiment names, numbers, filenames and commit SHAs.
- State when a conclusion was provisional, pre-commit or pending verification.
- Cite the source filename when reconstructing important decisions or results.
- Ask before changing canon, architectural constraints or the experimental
  sequence.
